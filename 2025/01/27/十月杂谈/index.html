3个月后才发的原因

当时写好了主体，但不知道怎么结尾就拖着没动…
后面又遇到一些事情，对写博客没有兴趣了，也就没有发…
现在我也不太想改了，干脆就发出来吧（

很早就像写点东西总结一下了，但忙的时候没时间写，闲的时候又懒得写，拖拖拉拉一直到现在，到了后面没什么事的时候，才动笔勉强写些东西。后面就简单总结总结这个月（或者说从九月末以来）的一些事情。

Mini search engine

首先就是 ads 的第一个 project，算是我第一次真正做点我觉得很有意思的事。也是在这次 project 中，我把暑假期间学习的一些东西真正投入到了实战中，比如：

  • 用 git 进行版本管理与多人协作（虽然只有两个人）
  • 用 makefile 解决了多文件编译、链接
  • 用 python 处理了 html 文件
  • 用 slidev 做了第一个 md 转 ppt
  • 第一次完全在 linux 环境下完成一个比较大的项目。

说实话还是蛮有成就感的一件事。唯一可惜队友用 typst 写的报告，没能让我用 latex 写（但之后把 latex 用的更熟了，也得抽空学一下 typst）。但我估计就是用 latex，就我现在这种不熟练的样子，也不会做的比他更好。

这个 project 我投入了不少时间，中途又连忙补学了一些 C++的知识，虽然不能说入门（没用到 C++真正精髓的东西），但至少也起了个头。我也学了一些搜索引擎相关知识，虽然都是二三十年前的老古董，但说实话，真正感觉我学的东西和实际生活有些联系了。

我们组的内容全都放在仓库了，要是有兴趣的话，也许也能看看。实验一仓库。

现代中外关系展示

国庆后，距离现代中外关系的展示题展示只剩下一周的准备时间。这算是我第一次尝试担任组长完整组织一次展示了，总体来说是有很多教训的。

我们展示题的主题是关于“是否要接受三人五步方案”。

由于也没有人提出想法（太社恐了…没好意思在下课大声喊大家集合…），我就采取“辩论赛”的形式，因为我觉得辩论赛可以很好的展示这一主题的正反两面。

但这里就是我这次展示最大的问题，主要来说有两方面考虑不周到：

  1. 辩论的总时长只有20分钟，时间上很局促，但辩论会让话题铺的非常广，每一方都需要考虑内政、外交、军事，并就论点给出一套“可行”的方案。一方面很局促，另一方面又格外广大，本身就是矛盾的。
  2. 队内大部分成员，包括我自己，辩论经验、历史事件分析、国际政治素养不足，而这个问题需要比较高的素养，这让我们没能在有限的时间内挖掘出最关键的问题，反而在一些简单的问题上反复争吵

然后第二轮，又由于第一轮讨论话题过广，讨论深度过浅，导致我在第二轮被问倒在台上，下不来台。最后第三轮总结成员又完全与第一、二轮的成员割裂开，有的人明明是报名总结，却在正式展示的前两天暴露出对话题的无比的无知（甚至都不了解三人五步方案），更别提一开始我的期望是他们能积极总结各种资料…

整个展示完全的展示出我们准备之不充分，思想之简单…真的让我有些无地自容…

值得议题的是，还有准备阶段，我尝试性的采用共享文档的方式来协调准备，但反响平平，大多数人还是没能积极参与进准备中，共享文档也没能起到减少重复工作的理想效果。如果想要查看的话，可以看展示题更细致的布置。

如果说这方面的教训的话，我觉得以后无论如何，必须要在准备前，先线下碰头达成一定的共识，确定相对集中的时间，细致的分配好任务。然后，真正找到一些很有兴趣参与的，而不是在线上填表格。

马原辩论

马原辩论的主题是“道德的本质是利他主义/利己主义”，很深也很广的一个问题，无论是问“道德是什么”“道德的本质是什么”“利他主义与利己主义关系”，都是非常棘手的。

（队友介绍了斯坦福大学哲学百科全书，我搜索了利己主义和利他主义，花了差不多一个多小时囫囵吞枣式的看，深刻的感受到自己思想的浅薄…）

这次我们队中有出来主持局面的，提前一周就拉大家出来考虑，最后解决方案有两部分：

  1. 将正方“道德的本质是利他主义”理解为“一个人践行道德更优先考虑他人”，反方则是“优先考虑自己”，解决了定义上的棘手问题；
  2. 自由辩论为表演赛，采取“故事接龙”（也是用共享文档）的准备形式

但由于效率原因，两队的立论在周二上午才全部发出，故事接龙也是在周三晚上才开始写（周四上午开始辩论）。但出乎我的意料的事，我们成功写完了自由辩论环节的内容，只不过内容质量无法恭维而已…真正展示时，也非常的假，毕竟大家每次发言的信息密度有点高，反驳、思考都不像是真的…只不过老师没有明确点出而已…

在总结阶段，被有辩论经验的队友带飞（她总结了两方在自由辩论环节的得与失，很好的表述了我方的核心观点和主要进攻点），成功获得了胜利。
